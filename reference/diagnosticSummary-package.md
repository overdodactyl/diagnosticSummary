# diagnosticSummary: Diagnostic Accuracy Summaries for Binary Classifiers

Summarizes how well predicted probabilities agree with a binary
reference standard.
[`dx()`](https://overdodactyl.github.io/diagnosticSummary/reference/dx.md)
calculates the measures, with confidence intervals, overall, across
thresholds, and by subgroup.
[`dx_itd()`](https://overdodactyl.github.io/diagnosticSummary/reference/dx_itd.md)
does the same when some predictions are missing,
[`dx_compare()`](https://overdodactyl.github.io/diagnosticSummary/reference/dx_compare.md)
compares models, and the `dx_plot_*()` functions draw the results. Each
measure is also available as its own function, such as
[`dx_sensitivity()`](https://overdodactyl.github.io/diagnosticSummary/reference/sensitivity.md),
from a confusion matrix made with
[`dx_cm()`](https://overdodactyl.github.io/diagnosticSummary/reference/dx_cm.md).
