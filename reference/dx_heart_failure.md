# Heart attack outcomes and predictions

A data set containing heart attack outcomes for 261 patients along with
predicted probabilities of having a heart attack.

## Usage

``` r
dx_heart_failure
```

## Format

A data frame with 261 rows and 5 variables:

- AgeGroup:

  Age group

- Sex:

  sex

- truth:

  Heart failure (outcome)

- predicted:

  Predicted outcome from a GLM model

- predicted_rf:

  Predicted outcome from a Random Forest model

- AgeSex:

  Age and sex group
